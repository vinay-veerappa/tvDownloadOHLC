# Strategy Validation Framework

Statistically validate trading strategies on futures 1-min data before building NinjaTrader bots.  
Designed for prop firm accounts with < $2,000 drawdown.

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Place your parquet files in data/raw/
#    Naming: {SYMBOL}_1min.parquet (e.g., ES_1min.parquet, NQ_1min.parquet)
#    Expected columns: datetime, open, high, low, close, volume
mkdir -p data/raw
cp /path/to/your/ES_1min.parquet data/raw/
cp /path/to/your/NQ_1min.parquet data/raw/

# 3. Run data preparation (creates cached CSV files — you only do this once)
python scripts/00_data_prep.py

# 4. Run all studies
chmod +x run_all.sh
./run_all.sh --skip-prep

# OR run individual studies
python scripts/01_opening_range_study.py --symbols ES NQ
python scripts/01_opening_range_study.py --or-durations 15 30 45

# 5. After reviewing results, run prop sim
python scripts/06_prop_sim.py --symbol NQ --strategy or_fade --monte-carlo 1000
```

## Architecture

```
strategy_validation/
├── config/
│   └── settings.py          ← All configuration (sessions, OR durations, instruments)
├── scripts/
│   ├── utils.py             ← Shared vectorized helpers (load, save, session filters, FVG detection)
│   ├── 00_data_prep.py      ← Parquet → cached CSV (daily levels, session ranges, opening ranges)
│   ├── 01_opening_range_study.py  ← Breakout rates, excursions, Judas swings, width analysis
│   ├── 02_session_sweep_study.py  ← London/Asia sweeps, NY response, overnight framing
│   ├── 03_key_level_study.py      ← PDH/PDL/ONH/ONL rejection/acceptance, gap fills
│   ├── 04_macro_time_study.py     ← ICT macro windows, FVG formation rates by time
│   ├── 05_weekly_profile_study.py ← Weekly extremes by day, continuation rates, ICT patterns
│   └── 06_prop_sim.py            ← Trade simulation + Monte Carlo
├── data/
│   ├── raw/                 ← Your parquet files go here
│   └── derived/             ← Cached CSVs (auto-generated by 00_data_prep.py)
├── results/                 ← Study output CSVs and JSONs
├── run_all.sh
├── requirements.txt
└── README.md
```

## Key Design Decisions

### Ticker-Agnostic
No symbol is hardcoded anywhere. Scripts auto-detect symbols from filenames.
Add any futures instrument by placing its parquet file in `data/raw/`.

### Configurable Opening Ranges
Default: 5, 15, 30, 45, 60 minutes. Change in `config/settings.py` or via CLI:
```bash
python scripts/01_opening_range_study.py --or-durations 10 20 30
```

### Cached Derived Data
Script 00 reads parquet ONCE and caches everything as CSV in `data/derived/`.
All subsequent scripts read CSVs only — fast iteration, no parquet dependency.

### Vectorized Performance
All analysis uses NumPy/pandas vectorized operations where possible.
Loop-based analysis (bar-by-bar trade simulation) is kept to minimum necessary scope.

## Configuration

Edit `config/settings.py` to change:

- **Session times** — Asia, London, pre-market, RTH boundaries
- **OR durations** — which opening range windows to analyze
- **Instrument specs** — tick size, point value, margins for any instrument
- **Prop firm rules** — drawdown, daily loss limit, max trades/day
- **Data paths** — input/output directories
- **Timezone** — raw data timezone (default: US/Eastern)

## Output Files Reference

### From 00_data_prep.py
| File | Contents |
|------|----------|
| `{SYM}_daily_levels.csv` | PDH, PDL, PDC, ONH, ONL, weekly open, gap, day-of-week |
| `{SYM}_session_ranges.csv` | Asia, London, pre-market OHLCV per day |
| `{SYM}_opening_ranges.csv` | OR high/low/width for each configured duration |
| `{SYM}_rth_1min.csv` | RTH bars with trade_date column |
| `{SYM}_eth_1min.csv` | Full ETH bars with trade_date column |

### From Study Scripts
| File | Key Metrics |
|------|-------------|
| `*_or_breakout_rates.csv` | % high/low broken, Judas rate, time to break |
| `*_or_excursion_stats.csv` | Post-breakout distance distributions |
| `*_or_judas_stats.csv` | False break details, fade R:R ratios |
| `*_or_width_analysis.csv` | OR width quintiles vs day behavior |
| `*_or_context_analysis.csv` | OR behavior near PDH/PDL/ONH/ONL |
| `*_or_day_of_week.csv` | All OR stats split by Mon-Fri |
| `*_london_asia_sweeps.csv` | London sweep patterns |
| `*_ny_response.csv` | NY reversal rates after London sweep |
| `*_key_level_stats.csv` | Rejection/acceptance at each level |
| `*_gap_fill_stats.csv` | Gap fill rates by size bucket |
| `*_time_window_volatility.csv` | Volatility by 20-min window |
| `*_macro_vs_nonmacro.csv` | ICT macro windows vs regular |
| `*_weekly_extreme_days.csv` | Which day makes the weekly high/low |
| `*_daily_continuation.csv` | Day-to-day trend continuation rates |
