# Edgeful Phase 1: Shared Infrastructure Layer

This library provides the foundational data infrastructure for the **Edgeful Market Analytics Platform**, implementing the shared layer that all downstream modules (macro, ranges, narrative) depend on.

## Architecture

Phase 1 implements three core abstractions:

```
┌─────────────────────────────────────────┐
│ Consumers: macro, ranges, narrative     │
│ (Dashboards, reports, alerts)           │
└─────────────────────────────────────────┘
                    ↑ reads
                    │
        ┌───────────┴──────────────┐
        │ daily_context.parquet    │
        │ (1 row/symbol/date)      │
        └───────────┬──────────────┘
                    │ generated by
        ┌───────────▼──────────────┐
        │ Phase 1 Library          │
        │ ├─ data_loader.py        │
        │ ├─ session_tagger.py     │
        │ ├─ context.py            │
        │ └─ filters.py            │
        └───────────┬──────────────┘
                    │ reads
        ┌───────────▼──────────────────────────┐
        │ Raw Data Sources                     │
        │ ├─ data/*.parquet (hist 1m/5m/daily) │
        │ ├─ data/live/* (live ~1y)            │
        │ ├─ data/VIX_1d.parquet               │
        │ └─ Prisma DB (economic events)       │
        └──────────────────────────────────────┘
```

## Modules

### 1. **data_loader.py** — Unified Parquet Loading

Entry point: `DataLoader` class with four public methods:

```python
from scripts.edgeful.lib.data_loader import DataLoader

loader = DataLoader(data_root="data")  # Default: repo_root/data

# Load 1-minute bars (historical + live fusion)
df_1m = loader.load_1m("NQ1", start_date="2024-01-01", end_date="2024-01-31")

# Load 5-minute bars
df_5m = loader.load_5m("NQ1")

# Load daily bars
df_daily = loader.load_daily("NQ1")

# Load VIX daily close
df_vix = loader.load_vix(start_date="2023-01-01")
```

**Features:**
- Automatic historical + live fusion (concatenate, deduplicate by timestamp)
- Intelligent timestamp normalization (Unix seconds → ms; convert to ET datetime)
- Caching within session (avoid re-reading same symbol/timeframe)
- Live ticker mapping (NQ1 → `-NQ`, ES1 → `-ES`, etc.)
- All timestamps converted to ET (America/New_York, naive per ADR-001)

**Output schema** (any timeframe):
```
Index: datetime (ET, naive)
Columns: open, high, low, close, volume
```

### 2. **session_tagger.py** — Trading Date & Session Classification

Entry point: `tag_session(df)` function

```python
from scripts.edgeful.lib.session_tagger import tag_session

df_tagged = tag_session(df_1m)  # df_1m must have naive ET datetime index
```

**Adds columns:**
- `trading_date` — Institutional trading date (rolls at 18:00 ET, skips weekends)
- `session` — Session name (7 types: ASIA, LONDON, NY_PRE, NY_AM, NY_LUNCH, NY_PM, ETH)
- `is_rth` — Boolean (True for 09:30–16:00 ET)
- `day_of_week` — 0=Monday, 4=Friday
- `minutes_into_session` — Signed integer (-180 before 09:30, 0–390 during RTH)

**Session windows (ET):**
- **ASIA**: 20:00–02:00 (overnight)
- **LONDON**: 02:00–08:00 (European open)
- **NY_PRE**: 08:00–09:30 (pre-market)
- **NY_AM**: 09:30–12:00 (morning)
- **NY_LUNCH**: 12:00–13:30 (lunch)
- **NY_PM**: 13:30–16:00 (afternoon)
- **ETH**: 16:00–20:00 (after-hours)

### 3. **context.py** — Daily Context Computation

Entry point: `DailyContextBuilder` class with main entry `compute_for_symbol(symbol)`

```python
from scripts.edgeful.lib.context import DailyContextBuilder

builder = DailyContextBuilder(loader)
ctx_df = builder.compute_for_symbol("NQ1")  # Returns DataFrame[DailyContext]

# ctx_df has one row per trading_date for NQ1
# Save to parquet:
ctx_df.to_parquet("data/derived/daily_context_NQ1.parquet", index=False)
```

**Output: DailyContext dataclass (60+ fields)**

#### Identity
- `symbol`, `trading_date`, `day_of_week`

#### Volatility
- `vix_close` — Prior day VIX close
- `vix_regime` — Classification (LOW < 15, NORMAL 15–20, HIGH 20–30, EXTREME > 30)
- `vix_pctile_60d` — VIX percentile over last 60 days (0–100)
- `atr_14d` — 14-day ATR (in points)
- `atr_usage_pct` — Intraday range as % of ATR

#### Prior Day Levels
- `pdh`, `pdl`, `pdc`, `pd_mid`, `pd_range`

#### Gap Analysis
- `gap_size_points`, `gap_size_pct`, `gap_direction` (UP/DOWN/NONE)
- `gap_size_bucket` (NONE/SMALL < 0.5%/MEDIUM 0.5–1%/LARGE > 1%)
- `gap_filled` (bool), `gap_fill_time_minutes` (int)

#### Overnight Action
- `overnight_high`, `overnight_low`, `midnight_open`
- `open_vs_midnight` (ABOVE/BELOW), `open_vs_pd_range`

#### Session Outcome
- `session_close`, `session_direction` (GREEN/RED)
- `pdh_broken`, `pdl_broken`, `both_pd_broken` (bool)
- `pdh_break_time_minutes`, `pdl_break_time_minutes` (int)

#### Streaks
- `streak_direction` (GREEN/RED), `streak_length` (int)

#### Economic Events
- `is_event_day` (bool)
- `event_type` — Primary category (first match)
- `event_types` — List of all matching categories
- `is_opex_week` (3rd Friday member)

#### Weekly Context
- `prior_week_high`, `prior_week_low`, `prior_week_close`, `weekly_open`

### 4. **filters.py** — Filter Dimensions

Declares all filter dimensions used across dashboards and reports.

```python
from scripts.edgeful.lib.filters import UNIVERSAL_FILTERS, MACRO_FILTERS, get_filter_by_name

# Discover available filters
fx = get_filter_by_name("vix_regime", UNIVERSAL_FILTERS)
print(fx.values)  # ['LOW', 'NORMAL', 'HIGH', 'EXTREME']

# Build SQL WHERE clause
from scripts.edgeful.lib.filters import build_filter_sql_expression

filters_dict = {"vix_regime": ["HIGH", "EXTREME"], "session_direction": "GREEN"}
where_clause = build_filter_sql_expression(filters_dict, UNIVERSAL_FILTERS)
# → "vix_regime IN ('HIGH', 'EXTREME') AND session_direction = 'GREEN'"
```

**Filter categories:**

- **UNIVERSAL** (13): Available on all reports
  - `day_of_week`, `vix_regime`, `gap_direction`, `gap_size_bucket`, `open_vs_pd_range`, 
  - `is_event_day`, `is_opex_week`, `atr_respected`, `session_direction`, `streak_direction`,
  - `event_type`, `both_pd_broken`, `lookback_days`

- **MACRO** (3): Macro module only
  - `judas_direction`, `indicator_class`, `session_group`

- **RANGE** (4): Range module only
  - `range_width_category`, `first_boundary_broken`, `close_vs_mid`, `range_name`

## Generation Workflow

### Quick Start

```bash
# Generate for all symbols (NQ1, ES1, YM1, RTY1, CL1, GC1)
python scripts/edgeful/lib/generate_daily_context.py

# Generate for specific symbols
python scripts/edgeful/lib/generate_daily_context.py --symbol NQ1 ES1

# Force regeneration (overwrite existing)
python scripts/edgeful/lib/generate_daily_context.py --force

# Validate output
python scripts/edgeful/lib/validate_daily_context.py --checks 20
```

### Output

Each symbol generates `data/derived/daily_context_{symbol}.parquet`:
- One row per trading_date
- Schema matches `DailyContext` dataclass
- Ready to join with macro_records, range data, etc. on (symbol, trading_date)

### Validation

Spot-check methodology (10 random dates per symbol):
1. **Schema check** — All required DailyContext fields present
2. **NaN leakage** — Critical fields (pdh, pdl, atr, gap) are non-null
3. **Numeric bounds** — Gap < 5%, ATR > 0, VIX pctile 0–100
4. **Event accuracy** — event_type is in known categories

## ADR Compliance

Phase 1 library enforces key architectural decisions:

| ADR | Decision | Implementation |
|-----|----------|-----------------|
| ADR-001 | ET timezone (naive) | All timestamps converted; no UTC after loading |
| ADR-002 | Statistical normalization | Vectorized pandas/numpy (no loops) |
| ADR-004 | Session windows & ALN | 7 sessions; 18:00 ET rollover; weekend skip |
| ADR-011 | Vectorization | 100% vectorized (numpy arrays, no .apply) |

## Troubleshooting

**Q: "No data for symbol FOO"**  
A: Symbol not in data/FOO_1m.parquet. Check `ls data/ | grep FOO`.

**Q: "ImportError: No module named 'scripts.edgeful.lib'"**  
A: Run from repo root: `cd /path/to/tvDownloadOHLC && python scripts/edgeful/lib/generate_daily_context.py`

**Q: "ValueError: trading_date is None"**  
A: All bars must have valid ET timestamps before calling tag_session(). Check DataLoader output: `df.index.tz` should be None (naive).

**Q: "NaN in atr_14d"**  
A: Normal for early history (< 14 trading days). Filled forward or excluded by downstream modules.
