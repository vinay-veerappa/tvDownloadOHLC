# First Presented v3: NQ1
## Percentage-Based TP/SL with Bias Filter & Extended Horizons

## Methodology
- **Discovery**: 1H window (first FVG/OB per hour)
- **Trade horizons**: Same trade measured at 1H, 2H, 3H cutoffs
- **Bias**: Previous-hour midpoint. Entry price > mid = long bias, < mid = short bias
- **TP/SL**: Fixed % of entry price. Bar-by-bar: first threshold hit determines outcome
- **Same-bar tie**: SL wins (worst case)
