# HOD/LOD Timing Analysis

Analyzed 4640 days of NQ1 data.

## Timing Modes
- Most Frequent HOD Hour: **16:00** (ET)
- Most Frequent LOD Hour: **18:00** (ET)

## Implication
If the Mode HOD is early (e.g. 10:00), holding to 16:00 exposes the trade to reversal risk.
This supports the 'Time + Trailing' logic: capture the HOD if it happens early, hold for EOD if trend persists.
